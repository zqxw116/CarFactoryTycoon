## 2단계 — 플레이 검증

### ① 도킹
차량이 게이트 지점에서 **감속하며 정지**하는가. 뒷차가 줄 서는가(LineTrafficManager 자동).
- 실패 시: `MainSpline` 자동 탐색 실패 가능 → Console 확인

### ② 부품 집기 — 이번 수정의 핵심
1. 작업자가 재고 벽 쪽으로 걸어가는가 (**떨림 없이**)
2. 부품이 **스택 맨 위 칸 위치**에서 등장하는가
3. 재고가 줄면 **등장 지점도 한 칸씩 내려오는가**
4. 부품이 **손에 붙어** 따라오는가 (가슴 앞 높이 — 머리 위면 실패)
5. 차 옆에 서서 부품이 부착점으로 들어가는가

> **제자리에서 떨면** 자기참조 루프 수정이 적용 안 됐거나 다른 원인이다.
> 부품이 손에서 어긋나면 `Carry Offset` → `Carry Euler` 순으로 조정.

### ③ 재고 LIFO
- 소모 시 **맨 윗층부터 평평하게** 걷히는가 (첫 기둥만 비면 버그)
- `Count`가 정확히 1씩 줄어드는가

### ④ 보상
체결 완료 시 코인이 **발생 위치에서 재화 UI로** 날아가는가.

### ⑤ 재고 고갈 → 클릭 개입
`Start Count`를 2로 낮추면 빨리 볼 수 있다.
1. 재고 0 → **라인 정지** + 머리 위 **주황 "부품없음"**
2. 재고 벽 클릭 → **+3** 보충 후 재개
3. 8초 안에 재클릭 → **차단**
4. **창고 클릭** → 쿨타임 즉시 초기화
5. 보충 후 다시 **맨 위부터** 집는가

### ⑥ 컨디션 / 휴식
기본값으론 10대에 2분 이상 걸린다. `Condition Cost Per Car`를 **25**로 올려 4대 만에 확인.
1. 컨디션 0 → **강제 휴식 10초**, 머리 위 "휴식중", 라인 정지
2. 유휴 중 작업자 클릭 → **선제 휴식 3초**
3. 작업 중 클릭 → 체결이 눈에 띄게 빨라지는가
4. **차 1대에 1회만** 차감되는가 ← 이번 수정. 게이지가 한 번에 25씩 떨어져야 정상

> 확인 후 `Condition Cost Per Car`를 **10으로 되돌릴 것.**

## 3단계 — 통과 후

1. **커밋** (사용자 요청 시에만)
2. 9-15 **보급 시스템 구현**으로 진행

### 보급 구현 전 확정 필요 (9-15 열린 질문)
1. 최소 잔량 **동률일 때** 기준 (거리 / 방치 시간), `IsBlockedByStock()` 공정 최우선 삽입 여부
2. 유저 클릭(+3, 8초)과 보급 작업자의 관계 — 대체인가 보조인가, 수치 밸런스
3. 보급 작업자 경로 — 라인·차량을 가로지르는가 통로를 따르는가 (9-6 8단계 경계)
4. `WorkerStation.workers[]` 배열 → 단일 참조로 바꿀지 (체결 작업자가 항상 1명이 되었으므로)
