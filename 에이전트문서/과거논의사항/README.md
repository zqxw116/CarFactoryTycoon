# 과거 논의사항

이 폴더의 문서는 **확정 이전의 검토·논의·검증 기록**입니다. 현재 방향은 이 문서들을 대체한 `../GAME_DESIGN.md`를 따릅니다.

| 파일 | 작성 | 내용 |
|---|---|---|
| `CODEX_GAME_DESIGN_REVIEW.md` | Codex, 2026-10-26 | 프로젝트 분석. 주문 기반 생산 운영 게임을 권장 |
| `CLAUDE_GAME_DESIGN_REVIEW_2026-10-26.md` | Claude, 2026-10-26 | 독립 분석. 택트 지휘형 라인 감독 게임을 권장 |
| `CLAUDE_VS_CODEX_REVIEW_COMPARISON_2026-10-26.md` | Claude, 2026-10-26 | 두 분석 비교·통합 |
| `PLAY_VERIFICATION_2026-08-20.md` | 2026-08-20 | 구 방향 1단계 플레이 검증 체크리스트 (구 `CarFactoryTycoon/PLAY_VERIFICATION.md`) |

이후 사용자 논의를 거쳐 방향이 **1인칭(근접 3인칭) 작업자 → 공장 관리**로 바뀌었습니다. 위 문서의 "주문·옵션 기반 운영" 권장은 더 이상 유효하지 않습니다. 시장 조사, 코드 현황 분석, 기술 선행 과제는 참고 자료로 계속 쓸 수 있습니다.
