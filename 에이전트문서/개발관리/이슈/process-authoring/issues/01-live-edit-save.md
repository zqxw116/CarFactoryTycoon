## 현재 상황과 원하는 결과
기존 도구는 실행 중 자동 이동을 저작 데이터로 캡처하지 않기 위해 일시정지 상태에서만 편집한다. 사용자는 일시정지·다시 불러오기 없이 실행 중에도 수치 및 Scene 오브젝트 드래그로 수정하고, 저장 버튼을 누르면 해당 값을 저장·적용하는 흐름을 원한다. 이것은 이전 사용법/명세의 일시정지 요구를 바꾸는 신규 요청이며 아직 구현되지 않았다.

## 범위와 재개 시 검토
- 실행 중에도 편집 창 수치와 Scene 드래그가 실제 편집 대상에 반영되어야 한다.
- 명시적 저장으로 저작 설정을 보존하고 메인에서도 같은 배치를 사용할 수 있어야 한다.
- 이동하는 작업자·차량·뼈의 현재 실행 pose와 사용자가 의도적으로 고친 저작값을 구분하는 방법을 검토한다. 현재 런타임 Transform 전체를 그대로 덮어쓰는 방법으로 확정하지 않는다.
- 저장 시 진행 중 작업에 즉시 적용할 항목과 안전하게 재적용할 항목의 처리 방식은 재개 시 판단한다. 사용자에게 불필요한 정지·재로드를 강제하지 않는 것이 목표다.
- Play 중 .cs 수정 금지는 유지한다. 런타임 설정 편집 허용과 소스 수정은 별개다.

## 완료 조건·검증 예정
실행 중 수치/드래그 수정, 저장, Play 종료·재진입 후 값 보존 및 메인 적용을 확인한다. 자동 모션이 저작값을 오염시키지 않아야 한다. 일시정지 강제나 사용자 수동 재로드 없이 관찰·편집 흐름을 검증한다.

## 의존성·승인 대기·검증 근거
