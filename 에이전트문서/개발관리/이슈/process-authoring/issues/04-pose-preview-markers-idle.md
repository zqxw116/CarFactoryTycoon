- 설계 판단: 기존 휴머노이드 IK/패키지 리깅을 유지. 고정 편집용 아바타·부품 복사본은 EditorOnly/DontSave 그룹으로 만들고 게임플레이 스크립트·물리·재고와 분리한다. 손목/팔꿈치 설정을 공유 프로필에 저장해 실제 작업자에도 적용. 기즈모로 좌우 도달 구를 표시하며 트리거는 통행을 막지 않는다. 도달성은 콜백 대신 같은 구의 명시적 기하 검사로 확인한다(배속/정지에도 안정).
- 제약: 기존 사용자 배치·그립 보존. 이미 저장된 비활성 경로를 자동으로 모두 덮어쓰지 않고 ‘전체 경로 켜기’를 제공. 새 경로는 기본 활성. 기존 0제어점은 직선과 같아 초기 동작을 보존.
- 계획: 기본값/API RED → 지점/UI/Idle → 공유 팔 자세·도달구 → 두번째 아바타 편집기 → 실제 Edit/Play 및 회귀 검증 → 문서.
- 검증: inactive 지점 라벨, 경로 start/end/C1/C2, 복사본 고유2개/cleanup/비저장·재고0소모, 손목/팔꿈치 변경 공유, 팔길이 도달 내/외, Idle 차량정지·worker home·작업중지, 재시도·기존체결/재고 회귀. 1배 시각 품질은 기술오차와 구분한다.

## 구현·중간 검증
- 역할별 색상·이름표, start/end/시작제어점/도착제어점, 12px 이상의 경로 묶음 간격, 기존 전체경로 켜기와 신규 경로 기본 활성. 기존 비활성 경로는 자동 덮어쓰지 않는다.
- 리깅용 모델 복사본/부품은 EditorOnly/DontSave. gameplay Worker 없음, 모든 복제 behaviours/physics 비활성. 실제 source와 분리된 공간에 고정 집기 pose. 손목/팔꿈치/팔 뻗기 비율과 녹색 손끝방향 화살표/설명. 저장은 기존 공유 프로필.
- 좌/우 어깨와 팔 길이를 재서 2개 SphereCollider trigger로 표현. 같은 구를 명시적 기하 검사하므로 접촉 콜백 누락에 의존하지 않는다. 실제 도달 범위 안에서만 손 뻗기 시작, 팔 뻗기 비율로 접근 거리 계산. 도달 한계와 도착 오차 여유 포함.
- Idle 정차/일반대기/자동작업 억제. 편집모드/미저장초안도 지원하며, Idle의 임시 배치를 저작값으로 오인하지 않도록 marker/snapshot 분리.
- RED→GREEN: 기본경로 비활성, 편집기가 actual assigned pose를 덮어씀, max reach .98 경계의 도착오차, Idle 저작값 변경, 미러 부품 손목접근방향(+.07m→기대 -.07m).
- Edit PASS: surface/복사본 고유·재고무소모/손목·팔꿈치 변화/실제 pose 소유권/trigger 도달 내외/Idle 저작값보존/미러 손목. 독립 검토2건 재현 후 수정. Play 검증 결과는 아래 최종 검증 참조.
- UI 캡처 중 다른 전체화면 앱이 가린 데스크톱은 판정에 쓰지 않았다. Unity Scene 자체 캡처를 사용. 첫 캡처의 이름표 겹침·리깅 공간 겹침을 수정. 최종 Unity Scene 캡처에서 색/이름·접촉/팔꿈치/대기점 표시를 확인.

- 추가 RED→GREEN: 고정 리깅 아바타가 실제 작업자의 보행을 따라 이동하던 문제, 편집모드 Idle이 런타임 서비스를 생성하던 문제, 편집 hull 준비가 원본 부품 레이어/콜라이더를 바꾸던 문제. 고정 home/직접 정차 배치/hull-only API로 수정. 게임의 기본 차량 물리 정규화는 기존 동작 유지.
- 실제 작업자의 몸통 반경은 RobotKyle 어깨 폭에서 산출(대표 .229m). 플레이어/기존 비prototype 작업자의 .32m 기본값은 보존. 집기/작업 도착 오차 .005m와 팔길이 여유 .015m 적용.
- 잘못 저장된 직접 작업 위치(0,0,0)를 자동 초기화/재계산하는 버튼 제공. 차종·손접촉·차체 외곽을 고려하며 원본 부품 물리는 수정하지 않는다.
- 오른쪽 문 지원 자세 검증 PASS: 작업자336표본 최대 손목 .09138134m, 로봇78표본 최대 접촉 .00000106624m, 각재고1/슬롯재충전. 기존 상체 보정 켠 초안에서 검증,15cm 기준 유지. 전체 공정 자연스러움 승인으로 확대하지 않는다.
- 임시 테스트 창은 사용자 창과 분리하고 DestroyImmediate로 OnDisable 정리한다. 네이티브 호스트가 없는 임시 창의 Close() 예외를 재현 후 수정했다.
