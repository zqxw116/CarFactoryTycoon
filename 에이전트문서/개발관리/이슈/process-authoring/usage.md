# 공정 편집 도구 사용법

## 어느 화면에서 무엇을 하나요?

- **Scene 뷰**: 실제 배치 편집. 오브젝트/기준점을 선택해 Unity 기본 W(이동), E(회전) 도구로 드래그한다.
- **Game 뷰**: Play 중 체결 동작을 관찰한다. 물체 배치는 Scene 뷰에서 한다. Game에서 우클릭을 누른 채 마우스로 시점 회전, WASD로 이동, Q/E로 상하, Shift로 가속, 휠로 앞뒤 이동한다. 커서를 가두지 않으며 Hierarchy/편집 창으로 바로 나갈 수 있다. 카메라는 일시정지·배속과 독립이다.
- **공정 편집 창**: 같은 배치의 수치 수정, 대상 선택, 저장·메인 적용·실행 제어. 수치와 Scene Transform 드래그가 양방향으로 연결된다.

## 배치 수정 순서

1. 메뉴 `Tools > CarFactory > Process Authoring > Open Workbench`. 필요하면 **공정 편집 씬 열기**로 `Assets/@Scene/ProcessAuthoringScene.unity`를 단독으로 연다.
2. 공정·차종·작업자/로봇팔을 고른다. **배치** 탭의 **편집 대상**에서 재고 더미, 집기 슬롯, 초기 배치, 일반 대기, 체결 전 대기, 작업 위치, 로봇 대기, 고용 표지, 정차점 등을 선택한다.
3. **Scene에서 선택**을 누른 뒤 Scene 뷰에서 W/E로 이동·회전하거나, 창의 위치·회전 수치를 바꾼다. 편집 모드에서는 실제 오브젝트를 움직인다. Play 중 실제 작업자/로봇을 선택하면 초기 배치 기준점으로 선택을 연결한다. 자동 보행/팔 움직임 자체는 설정에 기록하지 않는다. 빈 기준점은 `ProcessAuthoring/편집 기준점/공정_XX`에 있다. **선택 대상 보기**로 Scene 카메라를 맞출 수 있다.
4. 수치는 **라인 좌표(m)**다. X=라인 좌우 보정, Y=높이, Z=진행 방향이며 공통 횡거리 보정이 더해진다. Unity Inspector의 월드 X/Y/Z와 숫자가 다를 수 있다. 창에 실제 월드 위치도 표시한다. 재고 더미와 단일 집기 슬롯은 독립된 위치다.
5. **잡기** 탭은 대기 부품의 양손/팔끝 접촉점을 편집한다. **동선 · IK** 탭은 주체별 걷기/운반 곡선·차량 감지 박스·손 IK·상체/발 보정, **차종** 탭은 프리팹/부착점/그립/주유구·차종 보정, **공통** 탭은 횡거리·레일 폭 등이다. 모든 기준점의 이름·역할별 색상을 표시하고 선택한 대상의 이동/회전 핸들을 표시한다.
6. **설정 저장**으로 공유 프로필에 저장한다. 편집 모드의 **저장하고 메인 배치에 적용**은 메인에도 반영한다. 메인이 이미 열려 있고 다른 미저장 변경이 있으면 자동 저장하지 않고 dirty 상태를 보존한다. 등록 차종 프리팹 교체 후에는 **저장하고 등록 차종을 씬에 준비**도 누른다.

## 실행하며 수정하기

**관찰 시작 (Play)** 후 1회 실행/자동 반복으로 확인한다. **실행 중에도** 수치와 Scene 드래그를 편집할 수 있다. 일시정지나 다시 불러오기는 필수가 아니다. 다른 공정·모드로 전환해도 미저장 초안은 유지된다. 움직이던 작업자의 순간 자세를 자동으로 설정에 저장하지 않는다.

위치를 바꾸면 프리뷰에 적용되고 **설정 저장**으로 공유 프로필에 보존된다. **체결 재시도**는 처음부터 동작을 보고 싶을 때만 선택한다. 저장·수정만으로 재시도를 강제하지 않는다. 재시도는 실행 시작 재고를 복원한 뒤, 일반 대기 복귀나 차량 진입을 기다리지 않고 로봇팔/작업자가 바로 슬롯 집기를 시작한다. 첫 집기가 끝나면 차량을 출발시키며, 주체는 부품을 든 채 실제 차량 감지를 기다린 뒤 체결한다. 기본 1회 실행의 준비 흐름과 주유 재시도는 기존대로다. 정상 자동 반복은 계속 재고를 소비한다. 0.1~1배는0.1단위,1~20배는1단위다. 카메라 이동 속도는 이 배율에 따라 바뀌지 않는다. 창을 닫거나 Play를 끝내면 시간·커서를 복원한다.

## 부품 잡기 위치
1. **잡기** 탭에서 부품을 고르고 **현재 부품에서 잡기 위치 만들기**를 누른다. 기존 자동 위치를 출발점으로 삼아 이 공정 부품의 명시적 설정을 만든다.
2. 작업자 모드는 왼손/오른손을 고른 뒤 Scene의 해당 기즈모를 드래그하거나 부품 로컬 수치를 바꾼다. 손가락 방향과 몸 기준 운반 회전도 조정할 수 있다. 기본 운반 회전은 두 지점이 몸의 좌우로 오도록 생성한다.
3. 로봇팔 모드는 팔끝 접촉 한 점을 편집한다. 부품 회전 중에도 이 접촉점이 팔끝에 유지되도록 부품 루트 위치를 역계산한다.
4. 기즈모는 **잡기 탭에서 실제 집어갈 수 있는 대기 슬롯 부품에만** 표시한다. 더미에는 그리지 않으며, 슬롯이 비면 재충전될 때까지 숨긴다. Scene 뷰 Gizmos 표시를 켠다.
5. 수정 후 **설정 저장**. 실행 중에도 변경·저장할 수 있다. 작업자는 슬롯 앞에서 양손을 뻗고 접촉 확인 후 집으며, 도달하지 못하면 재고를 소모하지 않고 실패 사유를 표시한다. 슬롯 위치/높이와 손 지점을 조정한다.
6. 설정은 해당 공정 부품의 공통값이며 기존 차종 탭 양손 그립보다 우선한다. **자동 잡기 위치로 되돌리기**를 누르면 기존 차종/원본 그립으로 복귀한다. 차종별 모양 차이는 별도로 검증한다. 신규 전신 IK 솔버를 도입한 것은 아니다.

메인 게임은 Play를 끄고 `Assets/Car_Factory/DemoScene/Car_Factory 3.unity`를 단독으로 연 뒤 Play한다. TestPartsScene/WorkerInteractionLab은 별도로 보존한다.

## 자세 검증

손목 목표 오차(m)를 표시하고 블렌드 후15cm초과 시 그립/작업 위치/운반 경로 조정을 안내한다. 기본 엔진 자동그립은 아직 튜닝 대상이며 Animation Rigging을 전체 공정에 일괄 켜지 않는다. 실제 자연스러움은1배속에서 평가한다. 기능 PASS를 자연스러움 합격으로 해석하지 않는다.

## 두 작업자로 자세 편집 (2026-11-08)

- **잡기** 탭의 ‘리깅 작업자 함께 보기’를 켠다. 실제 작업자는 공정 동작을 수행하고, 옆의 고정 리깅 작업자는 집기 자세를 보여준다. ‘리깅 작업자 가까이 보기’로 확대한다. 편집용 모델·부품은 재고를 소비하지 않으며 씬/빌드에 저장되지 않는다.
- 왼손/오른손을 선택하고 **W=접촉점 이동, E=손목 회전**. ‘왼팔/오른팔 굽힘 보조점’은 어깨 기준 팔꿈치가 굽는 방향을 조절한다. 양손 접촉점만으로 팔 자세가 전부 결정되지 않는다. 수정한 공정 그립·손목·팔꿈치는 실제 작업자도 사용한다.
- **손끝 방향**의 녹색 화살표는 손이 부품에 접근하는 방향과 손바닥/손목 보정 기준이다. 개별 손가락 관절을 편집하는 기능이 아니다. 손목 회전과 함께 조절한다.
- 녹색 도달 구는 어깨부터 실제 위팔·아래팔 길이로 계산한다. 통행을 막지 않는 트리거이며, 작업자는 양손 목표가 도달 범위에 들어온 뒤 손을 뻗는다. ‘팔 뻗기’ 비율로 집기 접근 거리를 조정한다.
- 잘못 지정한 작업 위치는 **배치 → 작업 위치를 자동 기준으로 맞추기**로 현재 차종·손 목표·차체 바깥쪽 기준에서 다시 만든다. 작업 위치를 처음 활성화해도 이 기준을 쓴다. 이후 직접 편집할 수 있다. 손 목표가 차체 안쪽에 너무 깊거나 불가능한 경우 개별 위치 튜닝이 필요하다.
- **Idle · 차량 정차 / 작업자 일반 대기**는 차량을 공정 정차점, 작업자를 일반 대기점에 놓고 자동 작업을 억제한다. 체결 전 대기점과 일반 대기점은 다르다. 1회 실행/재시도로 작업을 다시 시작한다. Idle 임시 배치는 초기 배치 설정을 덮어쓰지 않는다.
- 경로는 묶음별로 간격을 띄웠으며 시작/끝/C1/C2를 색·이름으로 구분한다. 새 경로는 기본 사용. 예전에 저장한 비활성 경로는 **선택 작업자의 모든 경로 사용**으로 함께 켠다.
- 미저장 초안도 Play·1회 실행·재시도에 적용된다. 실행을 위해 먼저 저장할 필요가 없다. 공유 프로필에 보존하려면 **설정 저장**, 메인 배치 반영은 **저장하고 메인 배치에 적용**을 사용한다.
- 고정 리깅 모델은 집기 기준 자세다. 실제 애니메이션의 상체/발 보정까지 완전히 같은 정지 화면은 아니다. 자연스러움은 실제 작업자를 1배속으로 관찰하고 판단한다.

## 리깅 작업자 이동·기본 자세·동작 비교 (2026-11-08 후속)
- **양팔 앞으로 · 기본 집기 자세 (접촉점 유지)**: 접촉점은 보존하고 손목 자동 정렬을 켜며 손목 추가회전0·좌우 팔꿈치 기본값·팔뻗기98%로 초기화한다. 실제 어깨와 양손 축을 맞춰 기본 위치를 계산하므로 Idle 클립의 몸 비틀림 때문에 한쪽 팔만 굽지 않는다.
- **모델 손목 자동 정렬**은 휴머노이드의 실제 손/중지/검지/새끼손가락 본 축으로 손목을 계산한다. 여기서 손목 회전0은 모델에 맞춘 기준 자세이며 추가 보정은 그대로 수동 편집할 수 있다. 신규 잡기 생성에서도 이 기준을 쓴다. 기존 저장 그립을 일괄 재설정하지 않는다.
- **Scene에서 리깅 작업자 이동 / 회전**을 누르면 편집용 root가 선택된다. Idle/정지 상태에서 Unity W/E로 옮긴다. 부품은 제자리에 있고 작업자만 이동하며 양손 목표가 도달 구 밖이면 자연 Idle, 안이면 집기 자세를 표시한다. 이 편집용 위치는 공정별 프로필 초안에 저장되며 메인 작업자의 대기/작업 위치와 별개다.
- **Idle 버튼**은 실제 작업자 일반대기/차량정차와 함께 리깅 작업자를 기본 집기 위치로 되돌려 팔을 뻗은 기준 자세를 보여준다. 이후 드래그하면 다시 거리에 따라 Idle/집기 상태를 확인한다.
- **체결 재시도/실행**에서는 두번째 모델도 실제 작업자의 걷기·집기·운반·체결 본과 부품 동작을 옆 공간에 함께 재생한다. 두번째 Worker/재고 소비는 만들지 않는다. 이 동안에는 실제 동작 비교를 하고, 위치·팔 자세 편집은 Idle에서 한다. 손 접촉·손목·팔꿈치 설정은 실제 작업자가 계속 사용한다.

## 부품과 작업자 독립 회전·재고 배치 (2026-11-09)
- **잡기 → 부품 배치 → Scene에서 대기 부품 이동/회전**: 리깅 옆 부품을 W/E로 편집하면 실제 집기 슬롯에 반영된다. 작업자의 위치/방향은 따라 바뀌지 않는다. 아바타 자식을 클릭해도 작업자 전체 편집 대상으로 연결된다.
- **작업자 이동**에서 W/E로 위치/방향을 정한다. 이후 부품이나 접촉점을 바꿔도 배치한 방향을 유지한다. 자동 기준으로 다시 맞추고 싶을 때만 기본 집기 자세/Idle를 사용한다.
- **반대 면에서 잡기**는 양손 위치·접근 방향을 반전하고 반대 경계면으로 접촉점을 옮겨 기준 서기를 반대로 잡는다. 메시 bounds 기준 표면이므로 굴곡/손잡이는 개별 접촉점으로 미세 조정한다. 기존 수동 운반 각도는 새 양손 축 기준으로 초기화된다.
- **들고 걸을 때 부품 방향**은 집은 이후 몸에 대해 부품이 향하는 각도다. 슬롯이나 재고를 눕히는 회전과 다르다.

### 재고 배치 탭
1. 부품을 선택하고 **월드 기준 재고 배치 시작**. 해당 공정만 전환하며 다른 공정은 기존 배치 유지.
2. **부품 월드 회전** 또는 **대표 부품 한 개 선택**으로 E 회전. 회전된 실제 메시의 월드 크기를 다시 계산한다. 대표 부품 이동은 전체 오프셋으로 기록된다.
3. 높이/행/열 개수를 지정한다. 12슬롯·높이2·열6이면 바닥6묶음, 각2층. 고정 풀 수량에 맞춰 필요한 실제 행 수를 표시하며 마지막 행은 덜 찰 수 있다. 총 수량 중 한 개는 기존처럼 집기 슬롯으로 이동한다.
4. 간격은 **부품 실제 크기 + 빈 간격**(겹침 회피) 또는 **중심 간격 직접 지정**. X칸=열방향, Y칸=행방향, Z칸=월드높이 간격. 중심 간격은 부품 크기보다 작게 설정하면 겹칠 수 있다.
5. **시작점**은 첫 부품의 바닥 기준, **끝점**은 방향 기준이다. 지정된 개수·간격이 우선이므로 끝점을 넘어갈 수 있고 끝점이 멀어도 늘리지 않는다. Scene의 시작/끝 핸들과 월드 위치 입력을 함께 사용한다.
6. 전체/행마다/층마다 오프셋은 월드 벡터로 입력한다. 행 방향은 시작→끝의 수평 수직 방향, 높이는 항상 월드 Y. 부품 자체의 로컬 축이 돌아가도 배치 축은 따라 돌지 않는다.
7. 선택적으로 베지에와 시작/도착 제어점을 사용한다. 거리 기준 간격으로 샘플링하고 곡선 길이를 초과하면 끝 접선으로 이어진다. 부품 회전은 경로와 별개다. 굽은 구간의 크기 자동간격은 보수적으로 잡으며 밀집도는 중심 간격/오프셋으로 조정한다.
8. 슬롯은 처음 재고 회전을 공유한다. **대기 슬롯도 같은 방향**을 끄거나 잡기 탭에서 슬롯을 직접 회전하면 별도 방향으로 전환한다. 배치는 설정 저장, 메인은 저장하고 메인 배치에 적용.
