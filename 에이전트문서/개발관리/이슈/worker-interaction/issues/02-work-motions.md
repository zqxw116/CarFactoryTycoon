사용자가 추가한 Worker_Kyle_WorkMotions.fbx의 무릎·숙이기·이동 점프·오른손 망치 클립을 사용한다. 공정별 손 그립·대기점·부품 배치는 제작자가 조정한 값을 따른다. 기존 실험의 전신 IK 채택 판단은 [별도 이슈](01-adoption-review.md)에 있다.

## 메인 씬 대표 확인

Worker의 작업점 높이는 발밑 기준이다. 기본값은 완전 무릎 자세 0.62m, 서서 작업하는 높이 1.18m, 접근 중 보행과 섞기 시작하는 거리 1.1m다. 인스펙터 Worker 컴포넌트에서 조정할 수 있다. 점프의 실제 거리와 충돌은 플레이어 컨트롤러가 결정하고 Animator는 수직속도에 맞춰 자세를 재생한다. 망치는 오른팔과 손가락 레이어를 사용한다.

실행 중 작업자 복제본에서 0.55m 높이 목표를 주고 자세를 측정했다. 접근 거리 0.55m에서 무릎 혼합 가중치 0.559·무릎 굽힘 약 74°, 작업 위치에서는 1.0·약 128°였다. 0.90m 목표에서 숙이기 자세도 확인했다. 플레이어 이동 점프는 이륙→공중→착지, 캡슐 상승 1.143m였다. 망치 재입력은 처음으로 되돌아갔고 망치 머리 이동 0.547m와 실제 속도 레버 저속→고속 전환을 확인했다.

슬롯을 집을 때도 그립 높이와 현재 어깨 본으로 양손 도달을 계산한다. 0.55m 슬롯의 같은 양손 목표에서 서 있을 때 도달 불가, 무릎 자세에서 도달 가능을 확인했다(골반 높이 0.452m). 새 클립이 들어 있는 FBX는 기존 단일 클립 일괄 재임포트에서 제외했다. 낮은 슬롯의 모든 공정을 실플레이하지 않았다. 기존 FactoryCharacterChecks 전체 검사는 구 좌표·차량 준비 상태를 전제로 하여 현재 씬에서 통과하지 않았다. 위 런타임 대표 검사 및 최종 컴파일을 확인했다.

Unity 컨트롤러가 4클립 FBX의 서브에셋을 GUID로 직접 참조한다. 공유 커밋 시 해당 FBX와 같은 이름의 .fbx.meta를 함께 포함해야 한다. 현재 프로젝트의 *.meta 무시 규칙 때문에 이 파일은 기본 Git 목록에 나타나지 않는다.

### 추가 반영 — 실제 그립 높이와 무릎 관찰

작업점은 차량 부품의 실제 양손 그립(자동 그립 포함)으로 계산한다. 마지막 접근 걸음에서 허리를 먼저 낮추고 무릎을 굽히며, 운반·이탈에서는 일어서기 구간을 섞는다. 공정 편집에 작업 높이와 도착 자세 표시, 자동 그립 공정의 리깅 작업자 동시 보기 지원을 추가했다.

기존 차량의 9번 오른쪽 앞문 1.33m, 11번 앞범퍼 1.01m, 14번 바퀴 0.79m. 편집용 RobotKyle 표본의 왼무릎 굽힘은 각각 9°, 62°, 124°였고 0.55m 목표는 128°였다. 해당 높이의 실제 자세를 확인했으며 휠 공정 전체의 연속 체결은 이번에 검사하지 않았다. 실행 중 공정 편집에서 14번 바퀴 작업팀 → 작업자 → 체결 재시도. 잡기 탭의 ‘체결 중 리깅 작업자 함께 보기’로 두 모델을 비교한다.
