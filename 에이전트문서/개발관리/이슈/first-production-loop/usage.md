# 첫 납품 루프 조작과 현재 적용 범위
- 메인 Car_Factory 3에서 Play. 공정 편집 씬과 기존 튜닝 데이터는 그대로 사용한다. 새 흐름은 메인 prototype 모드에만 runtime으로 연결되며 메인 씬 파일에 배치를 덮어쓰지 않는다.
- 첫 차량은 한 대 자동 투입된다. 1 분사건, 우클릭 드래그 시점, 좌클릭 유지로 물을 분사한다. 차체를 돌아다니며 전체 외장을 씻는다. 아래쪽/개구부 속 내부 면은 외장 세척 대상이 아니다. 물이 닿은 곳부터 원색이 보이고 HUD에 진행률이 표시된다.
- 세척 후 2 조립. 대시보드 대기 슬롯을 바라보고 E로 집는다. 차량의 대시보드 자리를 보고 E를 유지하여 부착하고, 가까이 다가가 좌클릭 망치의 실제 접촉 3회로 체결한다.
- 첫 차만 전체 작업이 끝날 때까지 기다린다. 대차로 옆 인수 구간에 이동한 뒤 약정 납품금이 지급된다.
- 두 번째부터 현장 투입 터널을 가까이서 망치로 쳐서 한 대씩 요청한다. 작업 완료에 맞춘 자동 대기는 없다. 기존 속도 레버를 실제 망치로 두드려 저속→고속→정지→저속을 선택할 수 있다.
- 전체세척/필수체결 미완료 차량은 납품금0원과 이유를 표시한다. 체결별 잔돈은 이 새 루프에서 중복 지급하지 않는다.
- 열린 공정의 표지 근처에서 F. 표지 이름을 확인하고 1로 해당 공정 작업자 고용, 2로 다음 공정 해금, 3으로 해당 공정 로봇팔 구매·전환, 4로 공장 전체 자동 투입 구매(임시 400원). 자동 투입은 15게임초마다 1대를 요청하며 수동 터널과 최대 5대 대기열을 공유한다. 화면 버튼도 같은 기능이며 F/Esc로 닫는다. 작업 중인 공정은 마친 뒤 전환한다.
- 초기 납품100원, 첫 고용180원, 다음 공정200원은 검증용 임시값. FirstProductionSettings가 단일 설정이다. 새 공정은 다음 투입 차량부터 필수 작업과 약정 단가에 반영된다. 기존 차량 인수가 끝난 뒤 납품 지점이 이동한다.
- 전체 세척·두 번의 정상 납품·다음 엔진 공정 해금을 실제 입력으로 검증했다. 검증 범위와 후속 항목은 [작업 이슈](01-playable-delivery.md)를 확인한다. 현재 prototype의 기존 persistProgress=false를 유지하며 이번 작업에서 영구 저장 기능을 새로 만들지 않았다.

임시 가격은 FirstProductionSettings.cs의 기본값으로 분리돼 있다. 선택적으로 Resources/FirstProductionSettings 자산을 만들면 그 설정을 읽고, 없으면 해당 기본값을 사용한다. Play를 종료하고 메인 씬에서 다시 Play하면 현재 prototype은 새 세션0원으로 시작한다. 공정 편집 씬의 저장된 포즈·그립·재고 배치는 이 기능이 변경하지 않는다.
