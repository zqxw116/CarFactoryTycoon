# 구매형 자동 투입과 공용 대기열

Category: enhancement
Status: ready-for-agent
State: closed
Resolution: completed

열린 공정의 F 투자 창에서 4 또는 자동 투입 버튼으로 공장 전체에 한 번 구매한다. 임시 400원, 기존 스포너의 투입 간격 15게임초를 사용한다. 타이머는 구매 시 시작한다. 터널 수동 요청과 같은 대기열·준비 시간·차간 거리·풀·계약 배정을 이용한다. 대기 5대일 때 추가 자동 요청을 누적하지 않는다.

메인 씬 단일 Play 검사. 구매 자금을 준비해 잔액 부족·중복 구매 거절, 400원 차감, 수동 요청 공존을 확인했다. Play 중 요청 간격을 0.35초로 줄이고 레버를 정지해 차량 1대·대기 5대·추가 요청 거절을 확인했다. 다음 자동 요청 간격을 늘리고 고속 레버로 재출발 후 차량 2대·대기 4대, 신규 계약 100원, 잔액 0원이었다. 전체 납품 재플레이와 최종 가격 튜닝은 범위 밖이다.
