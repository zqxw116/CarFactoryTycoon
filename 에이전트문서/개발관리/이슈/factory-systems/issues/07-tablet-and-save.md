# 현장 태블릿과 공장 성장 저장

Category: enhancement
Status: ready-for-agent
State: closed
Resolution: prototype implemented

메인 공장에서 태블릿을 열어 운영 현황과 라인 약도를 읽고, 닫으면 이전 캐릭터 시점으로 돌아간다. 고용·공정 구매는 현장 표지를 사용한다.

공장별 로컬 저장에는 자금, 마지막 해금 공정, 공정 고유 ID별 사람·로봇 배치, 창고 보급 인원, 자동 투입, 누적 인수·불량·수입, 오늘 장부·근무 시간·발생 임금이 들어간다. 결제·납품이 반영된 프레임 이후 또는 10초 주기, 앱 일시중지·종료 시 저장한다. 정산 팝업에서 종료하면 이미 지불한 임금을 유지하고 다음 날 08시에 재개한다.

운행 중인 차량, 세척·체결의 부분 진행, 차량 대기열, 사용 중인 재고 수량은 세션을 넘기지 않는다. 새 공장에서는 첫 차량을 준비한다. 성장한 공장으로 복귀하면 수동 또는 구매한 자동 투입으로 새 차량을 받는다. 관리자 경제·차량 변경을 처음 실행하면 직전 일반 진행을 저장하고 다음 실행까지 테스트 변경을 분리한다.

## 메인 씬 재실행 검사

사용자의 일반 저장과 분리한 슬롯에서 검사용 자금 12,000원으로 현장 구매를 수행했다. 대시보드 작업자·엔진 해금·엔진 로봇팔·자동 투입·창고 직원 1명을 구매해 1,780원을 사용했다. 관리자 버튼으로 10,000원을 추가하고 26공정을 모두 개방한 뒤 Play를 종료했다. 재실행 결과 잔액 10,220원, 개방·납품 위치 2공정, 대시보드 작업자·활성 엔진 로봇팔·보급자 1명·자동 투입 및 특근 설정, 당일 구매비 1,780원이 일치했다. 관리자 세션은 해제됐다.

정규·특근 임금 60원·15원 정산 후 재실행해 2일 차, 지갑 10,145원, 당일 구매비 0원을 확인했다. 메인 카메라 렌더에서 양손 사이 기기에 라인 경로와 세척·작업·인수 표식, 잔액과 공정별 담당이 보였다. 같은 기기 화면의 좌표로 다음 페이지와 닫기를 실행했다. 1·3인칭 각각 복귀, 콘솔 오류 0건. 모바일 실기기와 독립 빌드는 미확인. 임시 슬롯을 지우고 Play 시작 씬 설정과 기존 공정편집 씬의 미저장 상태를 보존했다.
