# 열린 공정별 작업자 고용과 로봇 전환

Category: enhancement
Status: ready-for-agent
State: closed
Resolution: completed

메인 씬은 각 열린 표지에서 F로 선택한 공정을 고정한다. 1 작업자, 2 다음 공정 해금, 3 로봇. 기존 프로토타입의 직접 로봇 구매와 작업 중 전환 차단을 유지했다. 공정당 작업자 180원과 기존 로봇 1,000원은 임시값이다. 수동 작업이 남으면 HUD는 먼저 그 공정을 안내한다.

메인 씬 Unity Play에서 초기 투자용 자금과 표지 접근 위치를 준비해 잔액 부족, 잠긴 공정, 다른 표지 구매, 중복 구매 거절을 확인했다. 작업 중 엔진 작업자의 로봇 전환도 구매 자금이 충분한 상태에서 거절됐고 지갑과 작업자 상태가 유지됐다. 별도 새 세션에서 실제 F와 1·2·3 입력으로 대시보드 작업자→로봇, 엔진 해금·작업자 고용을 실행했다.

납품 시험은 세척·부착·망치·매출 완료 값을 주입하지 않았다. 해금 전 투입 차량은 전체 세척 후 대시보드 로봇 3회, 엔진 재고 유지, 납품 100원. 수동 투입한 다음 차량은 전체 세척 후 플레이어가 엔진커버 슬롯 집기·E 부착·망치 체결, 대시보드 로봇 3회, 엔진 작업자 3회 후 220원 지급. 정상 2대, 실패 0, 누적 320원, 두 번째 인수 후 잔액 220원. 재고는 대시보드 12→10, 엔진·커버 각각 12→11. 두 번째 차량의 세척 뒤 직선 시험 보행이 레버에 막혀 기존 우회점을 거쳐 같은 차량에서 재개했다. 별도 HUD 시험에서는 분사 API로 세척을 준비한 3공정 차량에 수동 엔진커버 안내가 우선함을 확인했다.

최종 Car_Factory 3 Edit, dirty=false, 컴파일 실패 없음. 기존 공정 편집 프로필·장면은 수정하지 않았다. 다음은 구매형 자동 투입과 대기열·정체이며 이후 하루 운영·정산을 연결한다.
