# 현장 관리자와 작업자 테스트 라인

Category: enhancement
Status: ready-for-agent
State: closed
Resolution: completed
Priority: P1 · 현장 애니메이션 확인

메인 씬의 관리자 테스트 도구를 유지한다. 패널은 작업 안내 아래에 있으며 접힌 상태로 시작한다. 1·2 키는 분사건·조립 전환 전용이고, 가까운 차량의 체결 상태 변경은 관리자 버튼으로 실행한다. 자금 1,000원 또는 10,000원 지급, 전체 조립 라인과 사람 작업자 배치, 테스트 차량 자동 세척, 다음 차량 투입을 제공한다. 자동 세척은 선택 사항으로 현재 차량과 이후 투입 차량에 적용된다. 전체 배치는 현재 Play에만 적용되며 기존 계약은 유지한다. 새 차량부터 전체 조립 작업이 배정된다.

분사건은 양 시점에서 같은 플레이어의 오른손과 손바닥을 따라간다. 카메라 중앙으로 조준하고 실제 노즐에서 물줄기와 세척 판정을 시작한다. 메인 씬 검사에서 1인칭·3인칭 건 본체 화면 내 위치, 손 본 장착, 도구 교체 확인. 정차 차량에 3인칭 조준 후 실제 노즐 광선으로 세척률 0.48%→2.91%. 자금 10,000원, 조립 공정 23곳·사람 24명, 선행 계약 1공정과 다음 계약 23공정, 관리자 자동 세척 확인.
