마지막 조립 공정을 열면 기존 주유 설비와 현장 고용 표지를 연다. 중간 납품 차량은 투입 당시 계약을 따른다. 최종 스캔 합격 차량은 주유소에서 대기하며 수동 노즐, 고용 주유원, 자동 노즐이 같은 정차·해제를 사용한다. 불량 차량은 주유를 건너뛰고 0원 처리된다. 주유 자체는 대금을 지급하지 않는다. 주유원과 자동화 구매 상태는 성장 저장에 포함된다.

2026-11-13 메인 씬 Play 표본. 검사용으로 세척·부품 상태와 검사 진입 위치를 준비했다. 직접 주유는 플레이어를 거치대와 주유구 근처에 놓고 E 입력이 사용하는 거리·차폐 검사와 노즐 메서드를 호출했다. 수동 주유 시간은 가속했다. 첫 중간 납품 100원, 먼 거리 집기 불가, 합격 차량 정지, 노즐 집기·연결·주유·반납과 정상 출고 1,600원을 확인했다. 미세척 차량 한 대가 불량 처리될 때 주유 횟수와 잔액은 그대로였다. 주유원과 자동 노즐도 차량 한 대씩 주유·출고해 주유 3회, 정상 4대(중간 납품 포함), 불량 1대를 확인했다. 일부 차량은 관리자 기능으로 라인을 개방해 준비했다.

별도 정상 저장 슬롯에서 고용 주유원 복원, 자동 주유 1,000원 구매 후 재실행해 자동 설비 활성·잔액 1,400원·주유원 급여 제외를 확인했다. 사용자 일반 저장 보존, 종료 시 메인 씬 Edit·미변경.
