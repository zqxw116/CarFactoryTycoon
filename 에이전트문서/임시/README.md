# 임시

새 md 문서를 **처음 만드는 곳**입니다. 분석, 검토, 비교, 프롬프트, 메모 등 종류와 관계없이 모두 여기에 먼저 만듭니다. 규칙 원본은 `AGENTS.md`의 "문서(md) 작성 규칙"입니다.

- 앞으로도 계속 참조할 문서 → 사용자 확인 후 `에이전트문서/`로 올립니다.
- 역할이 끝난 문서 → `에이전트문서/과거논의사항/`으로 옮깁니다.
- 필요 없는 문서 → 사용자 확인 후 삭제합니다.
- 일회성 문서는 파일명 끝에 작성일을 붙입니다 (예: `XXX_2026-10-27.md`).
- 이 폴더에는 오래 두지 않습니다. 세션을 정리할 때 남은 파일을 확인합니다.
