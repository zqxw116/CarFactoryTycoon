## 4. 직전 인계 (구 방향, 2026-10-26) — 참고용

> 아래는 방향 전환 직전 `GAME_DESIGN_PROGRESS.md`(현 `DEV_HISTORY_LOG.md`) 상단에 있던 인계 내용이다.
> **UI 시안·성장 규칙 항목은 새 방향에서 무효**이며, 배치·검증 사실만 참고한다.

- **성장 규칙 유지:** 사람 1명 시작, 현재 줄 전체 고용 후 다음 줄 개방, 다음 줄 첫 작업장만 제공. 4개 조립 줄/23작업장, 공정별 벨트·납품 종단 확장. 상세 원본 10-24.
- **최신 Unity 배치:** 최종 줄 간격 9m(Z 35/26/17/8/-1/-10), 창고 X80.6/Z14.35. 이전 16m 안은 사용자 피드백으로 폐기. 납품 부스는 깊이 4.825m, 이동거리 3.2m로 별도 단축. 로봇 로컬 관절·트리거 설정을 유지하며 행 전체/사람/재고/검사/주유/스플라인/바닥·벽·카메라를 함께 이동. 납품 반출축은 모든 방향에서 월드 -Z.
- **(구) 현재 우선순위:** Unity 실제 캡처 + 조작 가능한 HTML UI 승인. 시안 주소 https://carfactory-ui-review-1025.trueplume4.chatgpt.site (기존 비공개 유지).
- **(구) UI 결정 시안:** 작업자/보급자 개별 팝업, 아이콘 연결 연구 트리+오른쪽 상세 등.
- **미개방 구역:** 실제 설비 비활성화는 기존 성장 시스템 유지. HTML에서는 2D 차폐.
- **보류:** Unity 개인 강화·급여·관리 UI 통합, 지게차 실주행, 장시간 정체·처리량·전체 저장 통합/밸런스.
- **복원/검증:** Play 종료, 초기 사람1/로봇0, persistProgress=true, 씬 clean. 컴파일 성공. 전체 설비 포함 Nav 갱신 후 창고→23개 작업장 모두 PathComplete.
- **작업 방식:** 파일·설정·로그/API 우선. 캡처는 채팅 직접 표시. 변경은 미커밋이며 커밋/푸시는 요청 및 제목 승인 후 진행. 기존 TimeManager 수정 보존.
